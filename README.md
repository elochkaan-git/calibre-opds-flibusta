# Плагин Calibre для Flibusta OPDS

Небольшой плагин, добавляющий поддержку поиска книг на библиотечном ресурсе [Flibusta](https://flibusta.is). Работает в новых версиях Calibre (9.15+). Для установки скачайте файл из раздела Releases, после `Параметры > Плагины > Загрузить плагин из файла` и выбирайте скачанный архив. После устнановки необходимо перезагрузить Calibre. Теперь можно зайти в `Купить книги` и в конце списка магазинов выбрать Флибусту
